# Unit Converter - Spring Boot Project

A beginner-friendly Spring Boot application that demonstrates REST API design, service layering, and security basics through a simple **Unit Converter**.  This project is part of my backend learning journey.

---

## ✨ Features
- Convert units (KB ↔ MB, GB ↔ MB, etc.)
- RESTful API endpoints with Spring Boot
- Service layer abstraction (`@Service`, `@Autowired`)
- Role-Based Access Control (RBAC) with Spring Security
- Swagger UI integration for easy testing

---

## 🛠️ Tech Stack
- **Java** (OOP principles, REST API design)
- **Spring Boot** (Controllers, Services, Security)
- **Maven** (dependency management)
- **Swagger UI** (API documentation & testing)
